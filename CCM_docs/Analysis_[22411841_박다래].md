# 1. Introduction

캠퍼스 냥이 메이트 (Campus Cat Mate)는 캠퍼스 내 길고양이와 학생 및 구성원이 더욱 건강하게 공존할 수 있는 환경을 제공하기 위해 기획된 체계적인 돌봄 네트워크 구축 프로젝트입니다. 본 프로젝트의 유용성과 주요 특징은 다음과 같습니다.

## 주요 특징

### 실시간 위치 분석 및 시각화
일반 학생들이 제보한 데이터를 기반으로 고양이의 현재 위치와 예상 동선을 실시간 지도(Real-time Map)로 시각화하여 학생들에게 유용한 즐거움을 제공합니다.

### 중복 급여 방지 및 전문적 건강 관리
주기적으로 돌보는 인증된 사용자(Caregiver/Guardian)에게 전용 권한을 부여하여, 사료 급여 현황과 건강 상태를 체계적으로 기록하고 중복 급여를 방지합니다.

### 지능형 식별 알고리즘
사용자가 지도에서 선택한 위치와 고양이의 활동 좌표, 최근 제보 기반 AI 예측 위치, 과거 제보 시간대를 함께 비교하여 영역 매칭도가 높은 개체를 추천함으로써 제보 데이터의 정확성을 높입니다.

### 모델의 확장성 (범용성)
해당 시스템은 특정 학교에 국한되지 않고, 길고양이 돌봄 이슈가 있는 타 대학 캠퍼스나 주거 단지, 공원 등 다양한 커뮤니티에 맞춤형 솔루션으로 도입될 잠재력을 가지고 있습니다.

# 3. Domain Analysis

## 3.1 Domain Classes

### Student
- **Meaning:** 위치 제보 및 신규 고양이 등록 요청이 가능한 일반 학생 사용자.

### Caregiver
- **Meaning:** 사료 급여 및 고양이 건강 상태 모니터링, 위키 편집 권한을 가진 인증된 사용자.

### Admin
- **Meaning:** 시스템 전체 관리 및 사용자 권한 부여, 신규 고양이 등록 승인 권한을 가진 관리자.

### Cat
- **Meaning:** 개별 길고양이 객체이자 캠퍼스 내의 관리 대상 개체. Territory와 Routine Data를 속성으로 보유.

### Encounter Log / Report
- **Meaning:** 사용자가 고양이를 목격하고 시스템에 전송한 조우 기록. 구현 단계에서는 Report 데이터로 관리한다.

### Diet Log
- **Meaning:** 돌보미가 작성한 사료 급여 및 건강 모니터링 기록.

### Territory
- **Meaning:** 특정 고양이가 주로 활동하며 방어하는 캠퍼스 내 지리적 범위.

### Routine Data
- **Meaning:** 특정 고양이의 과거 제보 위치와 발견 시간대에서 추정하는 활동 패턴 데이터.

### Registration Request
- #3(요청)과 #4(승인) 사이의 가교 데이터.

### Caregiver Application 
- #12(신청)와 #10(관리)에서 다루는 신청 데이터 객체.

비밀번호 입력란: 자물쇠 아이콘이 있는 두 번째 입력 칸에 비밀번호를 입력.

중앙의 큰 초록색 [로그인] 버튼을 클릭.

권한: 고양이 제보, 돌보미 신청, 담당 고양이 돌봄 기록 등 권한에 맞는 기능을 사용할 수 있다.

* [경로 B] 비회원/방문자 접속 (조회 전용)

<img width="40%" alt="Image" src="https://github.com/user-attachments/assets/23096aff-6419-4964-a8e6-64d8eb1a491a" />

### [시스템 유저 매뉴얼] CCM 조회 전용(Guest) 모드 분석
조회 전용 모드는 계정 인증 없이 캠퍼스 내 고양이들의 위치와 기본 정보를 열람할 수 있는 제한적 접근 인터페이스다. 데이터 기록 및 분석 기능은 차단되며, 시각적 안내를 통해 로그인 필요성을 사용자에게 지속적으로 전달한다.

#### 1. 상단 로그인 유도 베너 (Conversion Banner)
화면 최상단에는 비회원 상태임을 알리고 로그인을 유도하는 고정 베너가 배치되어 있다.

상태 안내: "더 많은 기능을 이용하려면 로그인하세요"라는 문구를 통해 현재 사용 중인 모드의 한계를 명시한다.

즉시 이동: 우측의 [로그인] 버튼을 클릭하면 즉시 로그인 화면으로 리다이렉트되어 가입 및 인증 절차를 밟을 수 있다.

#### 2. 정보 열람 인터페이스 (View-only Access)
로그인 없이도 고양이의 생존 확인 및 위치 파악에 필요한 최소한의 데이터는 제공한다.

고양이 개체 조회: 상단 리스트에서 '치즈', '나비' 등 등록된 고양이를 선택하여 해당 개체의 지도상 위치를 확인할 수 있다.

실시간 상태 탭: 최근 제보 시간, 날씨 등 공공 성격의 데이터는 일반 모드와 동일하게 노출한다.

지도 데이터 시각화: 고양이의 현재 위치와 기본 이동 경로는 점선으로 표시되어 직관적인 정보 습득이 가능하다.

#### 3. 기능 제한 및 유도 버튼 (Restricted Actions)
쓰기 권한(Write)이나 심화 분석 데이터가 필요한 기능은 잠금 상태로 유지된다.

버튼 활성화 상태: 하단의 [제보하기] 및 [동선 분석 보기] 버튼은 로그인 후 이용 가능하다는 점을 명확히 하기 위해 아이콘과 함께 "로그인하고..."라는 문구로 변경되어 있다.

기능 차단: 해당 버튼 클릭 시 기능을 실행하는 대신 로그인 유도 팝업이나 화면으로 연결하여 무분별한 데이터 생성을 방지한다.

#### 4. 하단 네비게이션 제약
메뉴 구성: [지도], [히스토리], [동선 분석], [프로필] 탭은 유지되지만, 제보와 기록 작성처럼 데이터 입력이 필요한 기능은 로그인 제한이 걸리도록 설계되어 있다.

### [시스템 유저 매뉴얼] CCM (Campus Cat Mate) 회원가입 가이드

학번 입력창: 선택한 가입 유형에 맞는 정보를 입력합니다. 하단에 "숫자만 입력 가능"이라는 가이드 텍스트(Hint)를 제공하여 입력 오류를 방지.

### [시스템 유저 매뉴얼] CCM (Campus Cat Mate) 듀얼 모드 서비스
본 서비스는 사용자의 역할과 목적에 따라 Student(학생) 모드와 Caregiver(돌보미) 모드라는 두 가지 핵심 인터페이스를 제공한다. 사용자는 상단 셀렉터를 통해 환경을 실시간으로 전환하며 시스템을 조작한다.

#### 1. 인터페이스 공통 구성 요소
시스템의 일관성을 유지하기 위해 두 모드는 동일한 기본 레이아웃 프레임을 공유한다.

상단 검색 시스템: 고양이 이름이나 외형적 특징(예: 치즈, 점박이 등)을 입력하여 특정 개체를 빠르게 조회한다.

개체 선택 탭: 등록된 고양이들의 프로필 아이콘이 가로 리스트 형태로 배치되어 있다. 아이콘 클릭 시 해당 고양이의 현재 위치로 지도가 포커싱된다.

실시간 인터랙티브 지도: 고양이의 위치 마커, 최근 제보 기반 이동 경로, AI 예측 위치를 시각적으로 표기한다.

상태 알림 바: 상단 상태 영역을 통해 최근 제보 또는 돌보미 모드의 급여 기록 정보를 제공한다.

#### 2. 모드별 특화 기능 및 조작 방식
#### 2.1 Student 모드 (그린 테마: 관찰 및 제보 중심)
일반 사용자가 고양이를 발견하고 정보를 공유하는 데 최적화된 인터페이스를 제공한다.

상단 대시보드: 최근 제보 시간, 날씨 등 관찰에 유용한 환경 정보를 우선적으로 노출한다.

- 핵심 액션 버튼:

[제보하기]: 고양이 발견 시 지도에서 선택한 위치, 메모와 선택적 사진 URL을 시스템에 등록하고 저장 시점의 현재 시간을 제보 시간으로 기록한다.

[동선 분석 보기]: 누적된 제보 데이터를 기반으로 분석된 고양이의 활동 범위를 확인한다.

하단 네비게이션: [지도], [히스토리], [동선 분석], [프로필] 순으로 구성된다.

#### 2.2 Caregiver 모드 (오렌지 테마: 돌봄 및 기록 중심)
사전에 승인된 돌보미가 고양이의 건강과 급여 상태를 체계적으로 관리하는 인터페이스를 제공한다.

상단 대시보드: 담당 고양이의 최신 급여 기록과 현재 모드 정보를 제공한다.

- 핵심 액션 버튼:

[급여/건강 기록]: 먹이 제공 여부 및 외관상 건강 상태를 세부적으로 입력한다.

[위키 편집]: 고양이의 성격, 특징 등 기초 정보를 수정하거나 최신화한다.

[히스토리 보기]: 해당 개체에 대한 과거 돌봄 기록 전체를 검토한다.

하단 네비게이션: [지도], [히스토리], [동선 분석], [프로필] 순으로 유지되며, 담당 고양이 상세 카드에서 급여 기록과 위키 편집으로 진입한다.

## Caregiver 모드 전환 시
<img width="1536" height="1024" alt="Prototype_Caregiver" src="https://github.com/user-attachments/assets/c0c675e6-480d-49d7-b04a-56ec06c3621e" />

### [시스템 유저 매뉴얼] CCM 돌보미(Caregiver) 모드 상세 분석
본 화면은 캠퍼스 고양이를 직접 관리하는 사용자를 위한 케어 중심 인터페이스다. 일반 사용자용(Student) 모드보다 더 깊이 있는 관리 도구와 상태 데이터를 제공하는 것이 특징이다.

#### 1. 상단 컨트롤 및 상태 관리 인터페이스
사용자는 화면 상단에서 담당 고양이를 빠르게 선택하고 현재의 케어 상태를 한눈에 파악한다.

모드 셀렉터: 상단 좌측의 오렌지색 'Caregiver 모드' 드롭다운을 통해 모드 진입 여부를 확인한다.

담당 고양이 퀵 탭: 상단에 배치된 고양이 프로필 리스트에서 담당 고양이를 선택한다.

실시간 케어 태그: 담당 고양이별 최신 급여 기록을 시간 정보와 함께 표시한다.

담당 여부: 해당 고양이가 로그인한 사용자의 담당 개체인지 확인해준다.

예상 동선: 제보 데이터를 기반으로 고양이가 이동할 확률이 높은 경로를 시스템이 계산하여 제시한다.

#### 2. 지도 및 데이터 시각화 (Interactive Map)
지도는 단순한 위치 표시를 넘어 고양이의 '생활 패턴'을 시각화하는 도구로 활용된다.

동선 트래킹: 고양이 아이콘과 발바닥 아이콘 사이를 점선 화살표로 연결하여 고양이의 이동 경로를 표현한다.

위치 핀 (Pin): 고양이의 현재 추정 위치를 프로필 사진과 함께 노출하여 직관성을 높인다.

지도 이동: 선택한 고양이 또는 AI 예측 위치를 기준으로 지도를 이동하여 위치 정보를 확인한다.

#### 3. 고양이 상세 정보 및 액션 카드
화면 하단에는 선택된 고양이의 상세 프로필과 돌보미 전용 수행 기능이 배치되어 있다.

#### 3.1 상태 요약 (Status Card)
상태 인디케이터: 담당 고양이 여부, 비 오는 날 대피 가능성 등 현재 상황 정보를 배지로 표시한다.

상세 제원: 주 활동 영역, 추정 나이, 몸무게 등 관리 상의 필수 데이터를 한곳에 모았다.

#### 3.2 핵심 조작 버튼 (Action Buttons)
[급여/건강 기록]: 먹이 제공 여부와 고양이의 외관상 건강 특이사항을 기록하는 폼(Form)으로 연결된다.

[위키 편집]: 고양이의 이름 유래, 특징, 건강 상태, 주 활동 영역 등 고유 정보를 수정하여 공유한다.

[히스토리 보기]: 과거부터 현재까지 누적된 모든 돌봄 기록을 타임라인 형태로 열람한다.

#### 4. 실시간 알림 시스템
상단 급여 기록 영역: 담당 고양이별 최신 급여 기록을 표시하여 중복 급여를 방지하고 돌보미 간 기록 공유를 돕는다.

### [시스템 유저 매뉴얼] CCM 관리자(Admin) 모드 상세 분석
관리자 모드는 CCM 서비스의 전체 자원(고양이, 유저, 데이터)을 통합 관리하고 시스템의 운영 방침을 적용하는 운영 효율화 인터페이스다. 신뢰도 높은 커뮤니티 유지를 위한 승인 및 검토 프로세스가 핵심이다.

#### 1. 실시간 시스템 현황 모니터링 (Dashboard)
화면 상단에는 서비스 운영 상태를 직관적으로 파악할 수 있는 요약 대시보드가 배치되어 있다.

인사말 및 신원 확인: 로그인한 관리자의 정보를 상단에 노출하여 현재 관리 권한으로 접속 중임을 명시한다.

핵심 지표(Key Metrics) 카드:

전체 고양이: 현재 시스템에 등록된 총 고양이 개체 수를 표시한다.

총 제보 수: 시스템에 저장된 전체 제보 건수를 통해 데이터 업데이트 규모를 확인한다.

활동 돌보미: 현재 시스템에서 활동 중인 인증된 돌보미 수를 집계하여 관리 인력 현황을 파악한다.

#### 2. 핵심 관리 메뉴 및 조작 기능
중앙 영역에는 관리자가 수행해야 할 주요 승인 및 관리 도구가 배치되어 있다.

고양이 개체 관리: 등록된 고양이 목록을 조회하고 활성/비활성 상태를 관리한다.

돌보미 권한 승인: 신규 신청자의 자격을 검토하여 'Caregiver' 권한을 부여한다. 이는 시스템 보안 및 데이터 신뢰성을 유지하는 필수 관문이다.

신규 고양이 등록 승인: 사용자가 제출한 신규 고양이 등록 요청을 승인하거나 반려한다.

#### 3. 우선 처리 작업 리스트 (Recent Activities)
관리자가 즉각적으로 대응해야 할 이슈들을 리스트 형태로 제공하여 업무 누락을 방지한다.

승인 요청 알림: 새로운 돌보미 신청 및 신규 고양이 등록 요청 건수를 직관적으로 보여주어 빠른 권한 처리를 유도한다.

#### 4. 하단 네비게이션 인터페이스
관리 업무의 범주를 크게 네 가지로 분류하여 접근성을 높였다.

홈/통계: 현재의 대시보드 화면으로 이동하며 전체 운영 통계를 확인한다.

관리: 고양이 및 유저에 대한 세부적인 관리 리스트로 진입한다.

고양이 관리: 등록된 고양이의 상태 관리 화면으로 이동한다.

## 4.2.1 Login Screen (로그인 화면)

- 목적

사용자가 Campus Cat Mate 시스템에 로그인하여 개인 맞춤 기능(고양이 제보, 돌봄 관리, 위키 편집 등)을 이용할 수 있도록 한다.
또한 로그인 없이 조회 전용 모드로 진입할 수 있어 일반 사용자도 캠퍼스 고양이 정보를 쉽게 확인할 수 있다.

⸻

- 화면 구성

* 상단:
    * CCM(Campus Cat Mate) 로고 및 서비스 슬로건 표시
    * 캠퍼스와 고양이 일러스트를 활용한 친근한 분위기의 웰컴 화면 구성
* 중앙:
    * 아이디 입력 필드 (학번 또는 전화번호)
    * 비밀번호 입력 필드 및 비밀번호 보기 버튼
    * 메인 로그인 버튼
* 하단:
    * 로그인 없이 이용 가능한 “조회 전용 모드” 진입 버튼
    * 조회 전용 모드 설명 문구
        * 회원가입 화면으로 이동하는 회원가입 버튼
* 기타 UI 요소:
    * 전체적으로 친환경 느낌의 그린 컬러 기반 디자인 적용
    * 모바일 환경에 최적화된 세로형 레이아웃 구성
    * 직관적인 아이콘을 활용하여 접근성과 가독성 향상

 ## 4.2.6 Caregiver Real-time Map Screen (돌보미 모드 실시간 지도 화면)

돌보미(Caregiver)가 담당 고양이의 현재 예상 위치와 최근 급여 기록, 이동 동선을 실시간으로 확인하고 빠르게 돌봄 활동을 수행할 수 있도록 제공한다.

⸻

- 화면 구성

* 상단:
    * 고양이 이름 및 특징 검색창
    * 현재 사용 모드(Caregiver Mode) 표시
* 중앙:
    * 담당 고양이 선택 리스트
        * 담당 중인 고양이 프로필 표시
    * 실시간 지도 영역 (Kakao Map 연동)
        * 담당 고양이 예상 위치 마커 표시
        * 최근 제보 기반 이동 동선 시각화
        * 최근 제보 시간 및 담당 고양이 정보 표시
* 하단:
    * 담당 고양이 프로필 카드
        * 이름 및 상태 정보
        * 최근 제보 시간
        * 주요 활동 구역(Territory)
        * 추정 나이 및 체중 정보
    * 기능 버튼
        * 급여 기록 작성
        * 위키 편집
    * 최근 급여 기록 알림 배너 표시
    * 하단 네비게이션 바
        * 지도
        * 히스토리
        * 동선 분석
        * 프로필
* 기타 UI 요소:
    * 주황색 계열 기반의 돌보미 전용 UI 적용
    * 지도 중심의 실시간 관리 인터페이스 구성
    * 담당 고양이 정보를 빠르게 확인할 수 있는 카드형 레이아웃 제공
    * 모바일 환경에서도 빠른 기록 입력이 가능하도록 최적화

⸻

- 화면 구성

    * 뒤로가기 버튼
    * 화면 제목(급여와 건강 기록 작성)

    * 담당 고양이 정보 카드
        * 고양이 사진
        * 이름 및 담당 상태 표시
        * 주요 활동 구역(Territory)

        * 기록 시간 선택

        * 피부 이상

    * 기록 저장 버튼

 ## 4.2.9 Admin Dashboard Screen (관리자 대시보드 화면)

- 목적

관리자가 시스템 내 사용자, 돌보미 신청, 고양이 등록 요청 및 전체 운영 현황을 효율적으로 관리할 수 있도록 제공한다.
또한 승인/반려 및 데이터 관리 기능을 통합하여 시스템 운영의 편의성과 신속성을 향상시킨다.

* 상단:
    * 관리자 모드(Admin Mode) 타이틀 표시
    * CCM 로고 및 관리자 대시보드 헤더
    * 로그아웃 버튼
    * 통계 기준 날짜 표시
* 중앙:
    * 시스템 통계 요약 카드

        * 승인 대기 수

        * 신청자 이름
        * 대상 고양이
        * 현재 상태
        * 승인 / 반려 버튼 제공
    * 신규 고양이 등록 승인 영역
        * 임시 이름 및 특징 정보
        * 제보자 및 위치 정보 표시
        * 승인 / 반려 / 상세보기 버튼 제공

    * 빠른 관리 메뉴
        * 사용자 관리
        * 고양이 데이터 관리
* 기타 UI 요소:
    * 보라색 계열 기반의 관리자 전용 UI 디자인 적용
    * 카드형 레이아웃을 활용한 정보 시각화
    * 승인/반려 기능을 즉시 처리할 수 있는 직관적 인터페이스 제공
    * 모바일 환경에서도 관리 기능 수행이 가능하도록 반응형 구조 적용

## 6. Glossary

| Term | Definition |
| :--- | :--- |
| **Real-time Map (실시간 지도)**| 최근 수집된 조우 기록을 기반으로 고양이들의 현재 위치와 예상 동선을 지도 인터페이스상에 시각화하여 보여주는 기능. |
| **Path Analysis**| 최근 제보 데이터를 시간순으로 연결하여 고양이의 이동 흐름을 경로로 보여주는 기능. |
| **Encounter Check (조우 기록)** | 사용자가 캠퍼스 내에서 고양이를 발견한 위치와 시간을 시스템에 제보하는 행위. 제보 시 영역 기반 식별 알고리즘을 통해 해당 개체와 영역 매칭도를 추천한다. |
| **Caregiver Application** | 일반 학생 사용자가 돌보미 권한을 얻기 위해 관리자에게 승인을 요청하는 절차.|
| **Approve Caregiver** | 관리자가 신청자의 신원 및 활동 의지를 검토하여 돌보미(Caregiver) 권한을 최종 부여하는 행위.|
| **Mode Switch** | 돌보미 권한자가 일반 모드와 전문 돌봄 기능을 갖춘 '돌보미 전용 UI 모드' 사이를 전환하는 기능.|
| **Student (Observer)** | 위치 제보 및 신규 고양이 등록 요청이 가능한 일반 사용자. |
| **Caregiver (Guardian)** | 등록 요청 및 전문 돌봄 기록(식단, 건강) 권한을 가진 인증된 사용자. |
| **Territory (영역)** | 특정 고양이가 주로 활동하며 방어하는 캠퍼스 내 지리적 범위. |
| **Territory-based ID** | 현재 위치, 고양이 활동 좌표, AI 예측 위치, 과거 제보 시간대 유사도를 대조하여 영역 매칭도를 산출하고 후보를 추천하는 알고리즘. |
| **Approval Queue(승인 큐)** | 신규 고양이 등록 요청 및 돌보미 신청 건이 관리자 승인 전까지 머무르는 임시 대기 목록. |
| **Change History** | 위키 수정, 급여 기록, 제보 기록을 별도 데이터로 저장하여 고양이별 변경 및 활동 이력을 추적할 수 있게 하는 기록 방식. |
| **Recency Weight (최근 제보 가중치)** | 예측 모델에서 과거의 통계 데이터보다 최근(예: 1시간 이내)에 발생한 실제 제보 데이터에 더 높은 우선순위를 두어 실시간 위치를 보정하는 계산 방식. |
| **Diet Check (급여 기록)** | Caregiver가 고양이에게 제공한 사료의 종류, 양, 시간을 기록하는 행위. 중복 급여를 방지하는 핵심 데이터로 활용됨. |
| **Routine Data (루틴 데이터)** | 특정 고양이의 과거 제보 위치와 발견 시간대에서 추정하는 활동 패턴 데이터. |
